Бэкапы

Резервные копии конфигураций снимаются автоматически (задача backup_py, по умолчанию ежедневно в 01:00 — расписание меняется в «Настройки системы» → «Задачи планировщика»). Собирает скрипт backup.py: MikroTik — по SSH/SCP, свичи Ubiquiti/TP-Link — по SSH. Этот модуль — обзор всех локаций: что сбэкаплено, где изменения, где проблемы.

Структура хранения
/mnt/backups/<группа>/<объект>/          — объекты (группа = транслитерация типа локации, напр. salon для типа «Салон»)
/mnt/backups/<локация>/<устройство>/    — оборудование площадок (hardware)

MikroTik — два файла на прогон: .rsc (текстовый экспорт) и .backup (бинарный); свичи — .cfg (show running-config). Копии старше 365 дней удаляются автоматически.

Дашборд (карточки сверху)
  • Всего локаций — сброс фильтра
  • Свежие (до 24 ч) — бэкап снят в последние сутки
  • Нет бэкапа > 24 ч — проблемные: бэкап старше суток, старше двух суток или отсутствует вообще
  • Есть изменения — последний .rsc отличается от предыдущего: кто-то менял конфиг, стоит посмотреть diff

Клик по карточке фильтрует таблицу. Повторный клик по «Всего локаций» показывает всех.

Таблица локаций
  • Сортировка: тип локации (порядок задаётся полем «Порядок» в справочнике типов), затем имя
  • Стрелка ▸ у локации раскрывает список её устройств (у площадок с несколькими свитчами) — у каждого свой статус
  • Клик по локации — все её бэкапы справа; клик по устройству — только файлы этого устройства
Статусы и бейджи
  • «изменён» ставится только текстовым конфигам (.rsc, .cfg): бинарный .backup всегда отличается на несколько килобайт служебных данных, это не изменение конфига; служебная строка с датой экспорта в сравнении игнорируется
  • Кнопка diff — построчное сравнение двух версий (зелёное — добавлено, красное — удалено)
  • Кнопка ⬇ — скачать файл
Индексация

Базу наполняет скрипт backup_indexer.py (cron после ночных бэкапов): подхватывает новые файлы, обновляет изменённые, считает хэши и связи «предыдущая версия». Если в интерфейсе чего-то нет после бэкапа — сначала проверьте его лог: /var/log/macatlas/backup_indexer.log.
