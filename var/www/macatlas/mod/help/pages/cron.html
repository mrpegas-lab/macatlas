Фоновые задачи (cron)

Все сборы данных и бэкапы выполняются по расписанию. Расписанием управляет веб-интерфейс — «Настройки системы» → «Задачи планировщика», править crontab руками не нужно. Логи — в /var/log/macatlas/.

Как это устроено

В crontab одна постоянная строка — диспетчер job_runner.py (ставится install.sh):

* * * * * /usr/bin/python3 /opt/collector/job_runner.py >> /var/log/macatlas/job_runner.log 2>&1

Каждую минуту диспетчер:

  • пересобирает блок задач в crontab (между маркерами # --- MacAtlas jobs BEGIN/END ---) по реестру collector_jobs — если изменилось расписание или флаги включения;
  • выполняет ручные запуски из веб-интерфейса (кнопка «Запустить») и пишет их результат.

Каждая задача запускается через job_guard.py — он проверяет флаг включения в app_settings перед запуском: выключенная задача остаётся в crontab закомментированной.

Задачи по умолчанию

resolve_hostnamesПн–Пт 11:00Разрешение имён (PTR/NetBIOS) для адресов IPAM
harvestПн–Пт 12:20Сбор со свичей: порты, MAC-адреса, паспорт (версия, серийник, температура, PoE)
ipam_arp_syncПн–Пт 13:00ARP/DHCP с роутеров → IPAM + паспорт роутера (прошивка, серийник, модель, аптайм) в hardware
run_statПн–Сб 13:30Статистика роутеров объектов (mt_sites) — модель, версия, ресурсы → mt_devices
backup_pyежедневно 01:00Бэкапы конфигураций всего парка (backup.py): MikroTik — .rsc + .backup (SCP), свичи — show running-config (.cfg)
backup_indexerежедневно 02:40Индексация бэкапов в БД: новые/изменённые/удалённые файлы, связи версий и diff, поиск orphan-папок
Управление из веба
  • «Настройки системы» → «Задачи планировщика»: включить/выключить задачу, изменить cron-расписание (5 полей: мин час день месяц день_недели), запустить вручную
  • Изменения попадают в crontab в течение минуты автоматически
  • Ручной запуск работает даже у выключенной задачи; статус (в очереди / выполняется / успех / ошибка) виден прямо на странице
Ручной запуск из консоли

Любой скрипт можно запустить вручную из-под root — например, для отладки:

python3 /opt/collector/backup.py --ip 10.0.0.1           # бэкап одного устройства (dry-run)
python3 /opt/collector/backup.py --ip 10.0.0.1 --write   # то же с записью файлов
python3 /opt/collector/backup_indexer.py --prune --diff
python3 /opt/collector/run_stat.py --limit 3
Если после ручных правок в БД задачи не обновились в crontab

Правки collector_jobs напрямую в БД не выставляют флаг пересборки. Выставите его вручную:

mysql macatlas -e "INSERT INTO app_settings (name,value) VALUES ('crontab_dirty','1') ON DUPLICATE KEY UPDATE value='1';"

Блок в crontab пересоберётся в течение минуты (см. /var/log/macatlas/job_runner.log).
