Установка и конфигурация
Структура каталогов
/var/www/macatlas   — веб-интерфейс (корень виртуального хоста)
/etc/macatlas       — config.json и license.json (вне webroot!)
/opt/collector      — Python-скрипты фоновых задач
/mnt/backups        — файлы бэкапов
/var/log/macatlas   — логи фоновых задач
config.json

Единая точка настройки. Путь можно переопределить переменной окружения MACATLAS_CONFIG.

{
  "bd": {
    "dblocation": "localhost",
    "dbname": "macatlas",
    "dbuser": "...",
    "dbpasswd": "..."
  },
  "key": { "master_key": "..." },
  "backup_root": "/mnt/backups",
  "app": { "debug": false, "version": "1.3.0" },
  "FIRMWARE": {
    "DIR": "/var/www/macatlas/files/firmware/",
    "URL": "http://<адрес-сервера>/files/firmware/",
    "MODE": "prod"
  }
}
  • key.master_key — ключ шифрования паролей (credentials). Генерируется при установке; потеря ключа = потеря всех сохранённых паролей
  • app.debug — на проде держать false; app.version — версия продукта (показывается в «О программе»)
  • FIRMWARE — папка с пакетами RouterOS и URL, по которому устройства их скачивают; в папке же лежит version.txt с целевой версией
  • Доменная авторизация (LDAP) настраивается не здесь, а в интерфейсе: «Настройки системы» → «Доменная авторизация (LDAP)»
Требования
  • PHP 8+, MariaDB/MySQL, Python 3.10+ (paramiko, mysql-connector-python, cryptography, librouteros, pyyaml, lanname)
  • Cron с одной строкой-диспетчером job_runner.py (ставится install.sh); остальные задачи управляются из веб-интерфейса
  • Схема БД — актуальный дамп bd/macatlas.sql в комплекте установки
