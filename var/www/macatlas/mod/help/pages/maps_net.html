Карта сети (топология)

Интерактивная схема сети в стиле The Dude: устройства, соединения, блоки-комнаты, статусы доступности в реальном времени. Раздел «Сеть». Можно создавать несколько карт (например, ЦОД, офис, филиалы) — выбор карты сверху справа.

Узлы
  • Кнопка «+ Узел» — добавление устройства из справочника «Оборудование» (в списке только то, что ещё не на карте)
  • Перетаскивание мышью; клик по узлу открывает редактирование справа
  • Роль задаёт встроенную пиктограмму: роутер, свич, точка доступа, модем, сервер, компьютер
  • Удаление записи из «Оборудования» автоматически убирает узел с карты
Свои иконки
  • Файлы кладутся вручную в plugins/maps/icons/custom/ — SVG, PNG или JPG (прозрачный фон предпочтителен)
  • Выбор иконки — в форме узла, рядом со списком есть превью
  • Большие PNG/JPG автоматически ужимаются до размера из настроек (по умолчанию 96 px) — один раз, результат кэшируется в подпапке .cache/. Для ужатия нужно PHP-расширение GD
  • Картинка вписывается в квадрат иконки без искажений пропорций
Линки (соединения)
  • Выберите два узла (клик по первому, затем по второму) и нажмите «Линк» — соединение создаётся сразу и открывается на редактирование
  • Вид линии: изогнутая или ортогональная (прямые углы, как в drawio). Точки излома можно таскать, задав форму вручную
  • Цвет по умолчанию — серый; по скорости порта — свой (1G/10G/25G/40G/100G, стилистика drawio)
  • При мониторинге обоих концов линок перекрашивается по статусу: зелёный — связь есть, красный — нет
Блоки-комнаты
  • Кнопка «+ Блок» создаёт контейнер: комнату, кросс-шкаф, стойку. Заголовок редактируется в форме справа
  • Перетаскивание — за белую шапку (внутри блока устройства двигаются отдельно). Растягиваются за углы и стороны
  • Блоки прозрачные — видно, что под ними, узлы можно располагать внутри
Мониторинг
  • Для каждого узла выбирается метод проверки: ping, http, https, tcp (с портом), dns, ssh, snmp (по умолчанию — ping)
  • Статусы считает скрипт /opt/collector/ping_monitor.py по cron (каждую минуту, многопоточно — весь парк за секунды). Подробности — в разделе «Фоновые задачи (cron)»
  • Цвет узла: зелёный — доступен, красный — не отвечает, серый — мониторинг не настроен/выключен
  • Строки прошивки, uptime и температуры берутся из последнего сбора данных (harvest) — это не real-time, а последнее известное значение
Настройки отображения (кнопка ⚙)
  • Узлы: размер шрифта имени, размер иконки, сжатие картинок, какие строки показывать (модель, IP, прошивка, uptime, температура)
  • Выделение: цвет рамки выбранного объекта, тип линии (сплошная/пунктир), отступ
  • Блоки: шрифт, высота шапки, цвета шапки и рамки
  • Линки: цвета по статусу (up/down); пиктограммы: цвета для состояний
  • Фон и сетка: цвет фона, сетка вкл/выкл, картинка-подложка и её прозрачность. Подложки кладутся в plugins/maps/backgrounds/ (PNG/JPG/SVG) — например, план этажа

Настройки хранятся отдельно для каждой карты.

Права

Просмотр карты доступен при праве на раздел; редактирование (узлы, линки, блоки, настройки) — при праве на редактирование. Наблюдатели видят карту без кнопок изменения.
