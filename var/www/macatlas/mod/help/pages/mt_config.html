Конфигуратор объектов

Центральный модуль работы с объектами (роутерами MikroTik): создание, адресация, генерация конфигураций, статистика, бэкапы.

Вкладка «Редактировать»
  • Создать — сброс формы для нового объекта; кнопка генерации IP активна
  • Генерация IP — после выбора локации и группы (региона) выберите пул и нажмите кнопку: система сама найдёт свободные блоки (LAN /24, видео, IPIP /31, Loopback, WireGuard, Router-ID) и зарезервирует их при сохранении
  • У существующей записи генерация заблокирована — IP меняются только вручную (защита от случайной перезаписи)
  • Поле «Credentials» — учётные данные устройства из одноимённого справочника; используются сборщиками (бэкапы, статистика, мониторинг)
Вкладка «Конфиг»
  • Генерация .rsc из шаблона templates.tpl с подстановкой всех параметров объекта
  • Шаблон поддерживает условные блоки #{show:УСЛОВИЕ}...#{/if} — например, секция WAN добавляется только при наличии внешнего IP
  • Кнопка «Скачать» отдаёт файл ИМЯ_ЛОКАЦИИ.rsc
Вкладка «Скачать»

Файлы, относящиеся к выбранному объекту (сгенерированные конфиги и т.п.), с возможностью скачать прямо из интерфейса.

Вкладка «Backup»
  • Список бэкапов выбранного объекта: текстовые .rsc и бинарные .backup
  • Бейдж «изменён» — последний .rsc отличается от предыдущего (сравнение по хэшу без учёта комментариев)
  • Кнопка diff — построчное сравнение с предыдущей версией
  • Плашка-предупреждение появляется, если свежего бэкапа нет более суток
Вкладка «Статистика»

Аптайм, версия прошивки, модель и состояние устройства — данные собираются фоновыми задачами.

Одна локация — один объект

К локации может быть привязана только одна запись: при сохранении дубля появится красное предупреждение, и запись не сохранится. Если нужно менять параметры — откройте существующую запись этой локации.
