Массовые команды

Выполнение одинаковых команд RouterOS на группе устройств — для массовых изменений конфигурации.

Как пользоваться
  1. В левой панели введите команды — по одной на строку, как в терминале MikroTik
  2. Выберите объекты в таблице справа (или отфильтруйте и отметьте всех)
  3. Нажмите «Выполнить» — лог в нижней панели показывает ответ каждого устройства в реальном времени
Рекомендации
  • Сначала проверьте команду на 1–2 устройствах, потом раскатывайте на весь парк
  • Не запускайте больше ~20 устройств за раз — так проще отследить ошибку и откатить
  • Команды выполняются последовательно на каждом устройстве в порядке ввода
  • Команды с ожиданием ввода (reboot без подтверждения и т.п.) используйте с осторожностью
История

Модуль История запусков хранит все прошлые выполнения: кто, когда, какие команды и с каким результатом. Детали запуска раскрываются кликом.
