Обновление устройств

Массовое обновление прошивки (RouterOS) парка MikroTik.

Подготовка файлов прошивки

Перед обновлением парка нужно положить пакеты на сервер:

  1. Скачайте RouterOS (Main package) под все архитектуры, которые есть в парке: arm, arm64, mipsbe и т.д. — с сайта MikroTik
  2. Положите файлы в папку прошивок: /var/www/macatlas/file/firmware/. Имена файлов строго по шаблону: routeros-<версия>-<архитектура>.npk (например routeros-7.16.2-arm.npk)
  3. В файле version.txt в той же папке укажите целевую версию — одна строка, например 7.16.2
Как проходит обновление
  1. Скрипт читает целевую версию из version.txt
  2. Подключается к устройству и узнаёт его версию и архитектуру (system/resource)
  3. Если версия уже актуальная — пропускает устройство
  4. Ищет файл routeros-<версия>-<архитектура>.npk; если под эту архитектуру файла нет — ошибка «Файл прошивки не найден»
  5. Устройство скачивает пакет по HTTP с сервера MacAtlas и перезагружается в обновление

Поэтому комплект файлов должен быть полным: если в парке есть старые mipsbe-устройства, а файл положен только для arm — mipsbe не обновятся.

Запуск обновления
  1. В таблице видна текущая версия каждого устройства; устаревшие подсвечены относительно version.txt
  2. Выберите устройства (партиями до ~20) и запустите — лог внизу показывает прогресс по каждому: загрузка пакета, перезагрузка, проверка версии после
  3. Кнопка «Обновить Firmware» обновляет загрузчик (RouterBOOT) — отдельный, более редкий шаг
Рекомендации
  • Перед большой волной обновлений убедитесь, что ночные бэкапы свежие (модуль «Бэкапы»)
  • Устройство перезагружается — объект на пару минут без сети, учитывайте расписание работы локации
  • Начинайте с некритичных объектов, потом раскатывайте дальше
