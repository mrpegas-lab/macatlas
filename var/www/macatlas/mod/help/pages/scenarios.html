Типовые сценарии
Добавление нового объекта (полный цикл)
  1. Справочник → Локации: создайте локацию, заполните «Имя (для MikroTik)» — например MSK_700_EXAMPLE, выберите тип локации, расписание и часовой пояс
  2. Объекты → Конфигуратор: кнопка «Создать», выберите локацию и группу (регион), выберите пул адресов и нажмите «Сгенерировать» — все IP заполнятся автоматически
  3. Проверьте поля, укажите Credentials (учётные данные устройства), нажмите «Сохранить»
  4. Вкладка «Конфиг»: сгенерируйте конфигурацию по шаблону, скачайте .rsc и залейте на роутер
  5. После появления устройства в сети оно попадёт в ночной бэкап и на вкладку «Backup»
Кто и когда изменил конфиг устройства
  1. Откройте Бэкапы → Обзор бэкапов
  2. Нажмите карточку «Есть изменения» — останутся только локации с изменённым последним .rsc
  3. Выберите локацию → в списке файлов нажмите diff у свежего файла — увидите построчное сравнение с предыдущим (зелёное — добавлено, красное — удалено)
Восстановление конфигурации
  1. Бэкапы → выберите локацию → найдите нужный .rsc по дате
  2. Скачайте кнопкой ⬇ и загрузите на устройство (import или через Files в Winbox)
  3. Бинарный .backup восстанавливается через load backup на том же устройстве
Массовое изменение конфигурации на парке
  1. Объекты → Массовые команды: слева введите команды RouterOS (по одной на строку)
  2. Отметьте нужные объекты, запустите выполнение
  3. Следите за логом выполнения ниже — виден ответ каждого устройства
  4. Совет: сначала прогоните команду на 1–2 устройствах
Поиск свободного IP / выдача адресации филиалу
  1. IPAM → Пулы: выберите регион и назначение пула (LAN, видео, VPN)
  2. В конфигураторе объекта генерация резервирует блоки автоматически — вручную ничего считать не надо
  3. Занятые блоки видны в IPAM → Выделения пулов
