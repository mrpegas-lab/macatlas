Метки подставляются в текст команд для каждого MikroTik отдельно, значения берутся из карточки салона в базе. Чтобы увидеть, что подставится — включите «Тестовый режим» и нажмите «Выполнить».

Основной канал (WAN)
МеткаЧто подставляет
{WAN_IP}IP основного канала с маской, например 10.77.0.1/24
{WAN_IP_NOMASK}IP основного канала без маски, например 10.77.0.1
{GATEWAY}Шлюз основного канала
{DNS}DNS-серверы основного канала
Резервный канал (WAN2)
МеткаЧто подставляет
{WAN_IP2}IP резервного канала с маской
{WAN_IP_NOMASK2}IP резервного канала без маски
{GATEWAY2}Шлюз резервного канала
{DNS2}DNS-серверы резервного канала
Локальная сеть (LAN)
МеткаЧто подставляет
{LAN_IP}IP LAN с маской, например 10.77.1.1/24
{LAN_IP_NOMASK}IP LAN без маски, например 10.77.1.1
{LAN_MASK}Маска LAN, например 24
{LAN_NETWORK}Адрес сети LAN, например 10.77.1.0/24
{POOL}Диапазон DHCP-пула, вычисляется из LAN
Видеонаблюдение
МеткаЧто подставляет
{VIDEO_IP}IP подсети видео с маской
{VIDEO_NETWORK}Адрес сети видео
VPN и туннели
МеткаЧто подставляет
{IPIP_ADDRESS}Адрес IPIP-туннеля
{WG_PUBLIC}Публичный ключ WireGuard
{WG_PRIVATE}Приватный ключ WireGuard
{WG_IP}IP WireGuard
{ROUTER_ID1}Router-ID OSPF инстанс 31
{ROUTER_ID2}Router-ID OSPF инстанс 32
{LO_IP}IP loopback-интерфейса
Прочее
МеткаЧто подставляет
{NAME}Имя салона из справочника
{DHCP_CLIENT}Флаг использования DHCP-клиента
Условные блоки
СинтаксисЧто делает
#{show:HAS_WAN_IP}
...команды...
#{/if}		 Показывает блок, только если у устройства есть WAN IP
#{hide:HAS_WAN_IP}
...команды...
#{/if}		 Показывает блок, только если WAN IP нет
#{show:DHCP_CLIENT} / #{hide:DHCP_CLIENT} То же самое для флага «используется DHCP-клиент»
Если метка в тексте есть, а в этом списке — нет, MikroTik вернёт ошибку синтаксиса при импорте.
